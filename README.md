# Little Wonder

Play at **https://rokon12.github.io/little-wonder/**.

A happy play garden with bubbles, colors, counting, music, and more.

## Run locally

Open `index.html` in a modern browser. The game is self-contained and needs no installation or build.

## Publish updates

GitHub Pages serves the root of the `main` branch. Commit changes to `index.html` to update the live game. Keep `.nojekyll` so GitHub serves the HTML directly.
